## Projetos em destaque

### [Portal de Notícias](https://github.com/devhome915/portal-noticias)

Projeto full stack em desenvolvimento, utilizando React, TypeScript e Vite no frontend, com Node.js e Express no backend.

O sistema possui navegação por categorias, busca de notícias, páginas de detalhes e painel administrativo para gerenciar matérias.

Também trabalhei com autenticação Google, validação de dados, persistência local e testes automatizados utilizando Vitest e Supertest.

As próximas etapas incluem ampliar as integrações com Google Sheets e Drive e melhorar a cobertura dos testes.

### [Clone do Orkut](https://github.com/devhome915/orkut)

Aplicação inspirada no antigo Orkut, desenvolvida para praticar React, TypeScript e operações com APIs.

Implementei páginas de perfil, amigos, comunidades e um mural de recados com funcionalidades de criação, edição e exclusão.

Trabalhei também com validações, modais de confirmação, notificações, estados de carregamento e tratamento de erros.

O projeto utiliza JSON Server para simular uma API e possui um modo de demonstração com armazenamento local.

[Ver demonstração](https://devhome915.github.io/orkut/)

### [GestãoService](https://github.com/devhome915/Gestao-Service)

Projeto de um sistema de gestão para assistência técnica, pensado para organizar clientes, orçamentos e ordens de serviço.

O planejamento da primeira versão contempla autenticação, cadastro de clientes, busca e controle de acesso.

A proposta utiliza React, TypeScript e Vite, com integração futura ao Supabase e PostgreSQL.

O projeto está em evolução, com escopo e etapas documentados no repositório.

### [Puzzle Game — Quebra-cabeça 15 peças](https://github.com/devhome915/puzzle-game)

Jogo de quebra-cabeça deslizante desenvolvido com **React, TypeScript e Vite**, utilizando um tabuleiro 4×4 com 15 peças numeradas e um espaço vazio.

Implementei a lógica de movimentação das peças, permitindo apenas movimentos válidos para posições adjacentes ao espaço vazio.

O jogo também possui embaralhamento que mantém o quebra-cabeça solucionável, verificação da sequência correta e mensagem de vitória quando o jogador completa o desafio.

Esse projeto foi uma oportunidade de praticar lógica de programação, controle de estados e regras de interação com o usuário.

**Tecnologias:** React, TypeScript, Vite e Oxlint.

[Ver código no GitHub](https://github.com/devhome915/puzzle-game)
